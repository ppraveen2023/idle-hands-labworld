# Progress

This folder tracks the project as it happens.

| File | What it holds | When it changes |
|---|---|---|
| `STATUS.md` | Where things stand right now: done, in progress, next, blockers | Overwritten whenever the state changes |
| `YYYY-MM-DD.md` | One log per working day: what was done, what was found, what was decided | A new file each day, never rewritten afterwards |

The day logs are the raw material for the one-page report (due Thu 10 Dec) and for answering "how did you get here?" in Q&A. Design decisions and their reasons live in `../DECISIONS.md`; results live in `../FINDINGS.md`; prior work lives in `../RELATED_WORK.md`.
